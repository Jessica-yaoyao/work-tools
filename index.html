检索ID拆分与表格合并工具

本工具在浏览器本地运行：不会上传文件到服务器。适合处理“按自定义数量复制检索ID”和“多个结果表合并为一个表”。

① 检索ID拆分复制

支持 .xlsx / .xls / .csv。默认读取第一个工作表，并优先识别列名包含“检索id / 搜索ID / id / ID”的列。为避免长数字变形，所有 ID 都按文本处理。

② 多个Excel合并

支持一次上传多个 .xlsx / .xls / .csv 文件。默认读取每个文件的第一个工作表，以第一个文件的表头为准，后续文件自动跳过重复表头并纵向合并。
